## ۱. 🧰 جعبه‌ابزار مأموریت (دانلود قبل از شروع کار آفلاین)

برای این مأموریت به دو ابزار کلیدی نیاز داری تا داده‌هایت را ذخیره کنی و داخل جدول‌ها را با چشم ببینی:

### ۱. پایگاه داده PostgreSQL (نسخه محلی یا کانتینر)
- **چرا نیاز داریم:** قدرتمندترین، استانداردترین و مطمئن‌ترین پایگاه‌داده رابطه‌ای متن‌باز جهان.
- **لینک دانلود رسمی:** [دانلود PostgreSQL برای ویندوز](https://www.enterprisedb.com/downloads/postgres-postgresql-downloads)
- *(پیشنهاد: هنگام نصب، برای کاربر پیش‌فرض `postgres` یک پسورد ساده مثل `123456` یا `root` بگذار و پورت پیش‌فرض `5432` را تغییر نده).*
- **اگر داکر داری:** با یک خط دستور در ترمینال می‌توانی آن را بالا بیاوری:
  ```bash
  docker run --name safir-postgres -e POSTGRES_PASSWORD=root -p 5432:5432 -d postgres
  ```

### ۲. پکیج‌های کامل Prisma و درایور دیتابیس (دانلود قبل از قطع اینترنت)
ابزار **Prisma** یک ORM مدرن است. در نسخه ۷ و بالاتر، برای ارتباط مطمئن و مستقیم Node.js با PostgreSQL، علاوه بر هسته Prisma به درایور رسمی `pg` و آداپتور اختصاصی `@prisma/adapter-pg` نیاز داریم:
```bash
# پکیج‌های اصلی ارتباط با دیتابیس
npm install @prisma/client @prisma/adapter-pg pg dotenv

# ابزارهای خط فرمان و تایپ‌ها
npm install prisma @types/pg --save-dev
```
- **تست نصب بودن ابزار:**
  ```bash
  npx prisma --version
  ```

### ۳. ابزار بصری Prisma Studio (توکار و آفلاین)
- **چرا نیاز داریم:** با دستور `npx prisma studio` در ترمینال، یک پنل وب محلی زیبا باز می‌شود که تمام جدول‌ها، سطرها و ستون‌های دیتابیس را مثل نرم‌افزار اکسل نشان می‌دهد و نیازی به نصب هیچ نرم‌افزار سنگین دیگری نداری!

## ۲. الفبای دیتابیس به زبان یک کودک ۵ ساله (مفاهیم کلیدی)

> 🧒 **داستان این بخش:** فرض کن توی اتاقت یک تخته‌وایت‌برد داری و یک دفترچه خاطرات قفل‌دار با جلد چرمی. وقتی روی تخته‌وایت‌برد نقاشی می‌کشی یا شماره تلفن دوستی را می‌نویسی، با یک دستمال کشیدن ساده یا وزش یک باد، همه‌چیز پاک می‌شود! اما وقتی چیزی را در دفترچه قفل‌دار می‌نویسی، حتی اگر سال‌ها بگذرد و هزار بار بخوابی و بیدار شوی، برگه سر جایش است. تخته‌وایت‌برد همان حافظه موقت (RAM) است و دفترچه قفل‌دار همان دیتابیس (Database).
> 
> **این بخش جواب می‌دهد:** دیتابیس، جدول، سطر، کلید اصلی و رابطه دقیقاً چه مشکلی را حل می‌کنند؟

---

### ۲.۱. حافظه فرار (RAM) در برابر حافظه ماندگار (Disk & DB)

- **به زبان ۵ ساله:** رم مثل هوش لحظه‌ای توست؛ همین الان یادت هست ۲ ثانیه پیش چه گفتی، ولی اگر بخوابی و فردا بیدار شوی یادت می‌رود! هارد و دیتابیس مثل کشوی میز توست که وسایلت را امن نگه می‌دارد.
- **به زبان فنی:**
  - متغیرهایی که با `const fakeDatabase = {}` در کد می‌نویسیم، در حافظه **RAM** قرار دارند. به محض بسته شدن پروسه Node.js، تمام آن بایت‌ها آزاد می‌شوند.
  - پایگاه داده اطلاعات را روی دیسک سخت (SSD/HDD) ذخیره می‌کند و تراکنش‌ها را طبق استاندارد **ACID** ثبت می‌کند تا حتی اگر ناگهان کابل برق کامپیوتر کشیده شود، داده‌ها خراب نشوند.

---

### ۲.۲. دفترچه شطرنجی: جدول، سطر و ستون (Table, Row, Column)

در پایگاه داده، اطلاعات فله‌ای روی هم ریخته نمی‌شوند:

| اصطلاح | تشبیه کودکانه | تعریف فنی مهندسی | مثال در پروژه سفیر |
|:---|:---|:---|:---|
| **جدول (Table)** | یک برگه جدول‌بندی‌شده مخصوص یک موضوع خاص | مجموعه‌ای ساختاریافته از رکوردهای هم‌جنس | جدول سفارشات (`orders`) |
| **ستون (Column / Field)** | سرستون‌ها که مشخص می‌کنند چه چیزی باید نوشته شود | ویژگی مشخص با نوع داده معلوم (متن، عدد، تاریخ) | ستون وضعیت (`status`) |
| **سطر (Row / Record)** | یک خط کامل که اطلاعات یک سفارش مشخص را در خود دارد | یک نمونه واقعی ذخیره‌شده از آن موجودیت | سطر سفارش شماره ۱۰۱ |

---

### ۲.۳. شماره شناسنامه: کلید اصلی (Primary Key - PK)

- **به زبان ۵ ساله:** در مدرسه ممکن است سه نفر اسمشان «علی محمدی» باشد! ناظم چطور آن‌ها را از هم تشخیص می‌دهد؟ با «کد ملی» یا «شماره پرونده».
- **به زبان فنی:** **کلید اصلی (Primary Key)** یک ستون ویژه در جدول است که مقدار آن در تمام جدول **کاملاً یکتا و تکرارنشدنی** است. در پروژه سفیر، هر مشتری یک `id` و هر سفارش یک `orderNumber` یکتا دارد تا هرگز دو سفارش با هم اشتباه نشوند.

---

### ۲.۴. وصل کردن دو برگه به هم: رابطه و کلید خارجی (Foreign Key & Relation)

- **به زبان ۵ ساله:** فرض کن یک برگه داریم مخصوص اسامی بچه‌ها، و یک برگه داریم مخصوص اسباب‌بازی‌ها. بالای برگه اسباب‌بازی می‌نویسیم: «این ماشین مال کودکی با کد شناسنامه ۱۲ است». حالا دقیقاً می‌دانیم اسباب‌بازی مال کیست!
- **به زبان فنی:** **کلید خارجی (Foreign Key)** ستونی در یک جدول است که به کلید اصلی جدول دیگری اشاره می‌کند. 
  - یک مشتری می‌تواند ۱۰ سفارش داشته باشد (**رابطه یک به چند / One-to-Many**).
  - به جای اینکه نام مشتری را در هر ۱۰ سفارش تکرار کنیم، فقط `customerId` را ثبت می‌کنیم.

```text
┌───────────────────────┐             ┌──────────────────────────────────┐
│   جدول مشتریان (Customer) │             │      جدول سفارشات (Order)        │
├───────────────────────┤             ├──────────────────────────────────┤
│ id: "c1"  (کلید اصلی)  │ ──(دارد)──> │ id: "o101"                       │
│ name: "بهنام"          │             │ item: "هدفون گیمینگ"              │
│ phone: "0912..."      │             │ customerId: "c1"  (کلید خارجی)   │
└───────────────────────┘             └──────────────────────────────────┘
```

---

### ۲.۵. چرا ابزار Prisma (مفهوم ORM)؟

- **به زبان ۵ ساله:** اگر بخواهی با یک آشپز آلمانی صحبت کنی، یا باید خودت آلمانی یاد بگیری (زبان سخت SQL)، یا یک مترجم مهربان کنارت باشد که حرف‌های عادی‌ات را به آلمانی ترجمه کند.
- **به زبان فنی:** ابزار **Prisma** یک **ORM** (مخفف Object-Relational Mapper) است. به جای نوشتن کوئری‌های خام و پرخطای متنی مثل:
  ```sql
  SELECT * FROM "Order" WHERE "status" = 'تحویل پست داده شد';
  ```
  با کدهای امن و اتوکامپلیت تایپ‌اسکریپت می‌نویسی:
  ```javascript
  const orders = await prisma.order.findMany({
    where: { status: 'تحویل پست داده شد' }
  });
  ```

### گام ۱: آماده‌سازی اولیه Prisma در پروژه

در ترمینال همان پوشه پروژه (`C:\safir-project`) دستور زیر را بزن:

2. یک فایل متنی به نام `.env` در ریشه پروژه می‌سازد که آدرس اتصال به پایگاه داده در آن نوشته می‌شود.

### گام ۲: تنظیم آدرس دیتابیس در فایل `.env`

فایل `.env` را در ادیتور باز کن و آدرس دیتابیس PostgreSQL محلی خودت را تنظیم کن:

```env
# قالب آدرس: postgresql://USER:PASSWORD@HOST:PORT/DATABASE_NAME
DATABASE_URL="postgresql://postgres:root@localhost:5432/safir_db?schema=public"
```
*(به جای `root`، رمزی که موقع نصب PostgreSQL انتخاب کردی را بگذار).*

### گام ۳: تعریف مدل‌های داده‌ای در `prisma/schema.prisma`

فایل `prisma/schema.prisma` را باز کن و محتوای زیر را در آن جایگزین کن:

```prisma
// prisma/schema.prisma — نقشه بایگانی پایگاه داده پروژه سفیر

generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

// ۱. مدل مشتریان (Customer)
model Customer {
  id        String   @id @default(uuid()) // تولید شناسه یکتای تصادفی
  name      String
  phone     String   @unique              // شماره موبایل نباید تکراری باشد
  createdAt DateTime @default(now())

  // روابط
  orders    Order[]                       // یک مشتری می‌تواند چندین سفارش داشته باشد
  messages  ChatMessage[]                 // تاریخچه پیام‌های چت این مشتری
}

// ۲. مدل سفارشات (Order)
model Order {
  id          String   @id @default(uuid())
  orderNumber String   @unique            // شماره پیگیری سفارش (مثلاً 101)
  itemTitle   String                      // نام کالا
  status      String   @default("ثبت اولیه") // وضعیت فعلی بسته
  city        String                      // شهر مقصد
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  // اتصال به مشتری (رابطه با جدول Customer)
  customerId  String
  customer    Customer @relation(fields: [customerId], references: [id])
}

// ۳. مدل پیام‌های چت سفیر (ChatMessage)
model ChatMessage {
  id        String   @id @default(uuid())
  sender    String                        // چه کسی پیام داد؟ (کاربر یا ربات)
  content   String                        // متن پیام
  createdAt DateTime @default(now())

  // در صورت مشخص بودن، به کدام مشتری تعلق دارد
  customerId String?
  customer   Customer? @relation(fields: [customerId], references: [id])
}
```

## ۴. بازنویسی سرور با حافظه ابدی (`server.js`)

> 🧒 **داستان این بخش:** در گام اول، تلفنچی ما روی هوا و توی ذهنش جواب می‌داد! حالا به تلفنچی یاد می‌دهیم هر پیامی که رسید، ابتدا توی دفترچه دیتابیس ثبتش کند، و برای استعلام سفارش به سراغ کشوهای محکم دیتابیس برود.
> 
> **این بخش جواب می‌دهد:** چطور کدهای Fastify را با Prisma Client متصل کنیم تا اطلاعات واقعاً در دیتابیس ذخیره و خوانده شوند؟

فایل `server.js` در پروژه را باز کن و با کدهای زیر جایگزین کن:

```javascript
// server.js — نسخه ۳: گام دوم (اتصال به دیتابیس پایدار با Prisma)

const fastify = require('fastify')({ logger: true });
const { PrismaClient } = require('@prisma/client');

// ایجاد نمونه از کلاینت دیتابیس
const prisma = new PrismaClient();

// ۱. بررسی وضعیت سلامت و ارتباط با دیتابیس
fastify.get('/health', async (request, reply) => {
  try {
    // یک کوئری بسیار سبک برای تست اتصال زنده دیتابیس
    await prisma.$queryRaw`SELECT 1`;
    return {
      status: 'healthy',
      database: 'connected (PostgreSQL)',
      uptime: process.uptime(),
      timestamp: new Date().toISOString()
    };
  } catch (err) {
    reply.status(500);
    return {
      status: 'unhealthy',
      database: 'disconnected',
      error: err.message
    };
  }
});

// ۲. مسیر دریافت پیام چت و ذخیره ابدی در پایگاه داده
fastify.post('/api/chat', async (request, reply) => {
  const body = request.body;

  if (!body || !body.message || body.message.trim() === '') {
    reply.status(400);
    return { success: false, error: 'متن پیام نمی‌تواند خالی باشد!' };
  }

  const userMessage = body.message.trim();
  const userName = body.name || 'کاربر ناشناس';
  const userPhone = body.phone || '09000000000';

  try {
    // الف) اگر مشتری با این شماره قبلاً ثبت نشده، پیدایش کن یا بسازش (upsert)
    const customer = await prisma.customer.upsert({
      where: { phone: userPhone },
      update: { name: userName },
      create: { name: userName, phone: userPhone }
    });

    // ب) پیام کاربر را در جدول پیام‌های دیتابیس ذخیره کن
    const savedUserMsg = await prisma.chatMessage.create({
      data: {
        sender: 'کاربر',
        content: userMessage,
        customerId: customer.id
      }
    });

    // ج) پاسخ دستیار سفیر را تولید و ذخیره کن
    const botReply = `درود ${customer.name}! پیام شما («${userMessage}») در سامانه ثبت شد و در پایگاه داده ذخیره گردید.`;

    const savedBotMsg = await prisma.chatMessage.create({
      data: {
        sender: 'سفیر (سیستم)',
        content: botReply,
        customerId: customer.id
      }
    });

    return {
      success: true,
      customerId: customer.id,
      userMessageId: savedUserMsg.id,
      reply: botReply,
      createdAt: savedBotMsg.createdAt
    };
  } catch (err) {
    fastify.log.error(err);
    reply.status(500);
    return { success: false, error: 'خطا در ذخیره‌سازی داده در پایگاه داده' };
  }
});

// ۳. مسیر استعلام وضعیت سفارش از دیتابیس بر اساس شماره پیگیری
fastify.get('/api/orders/:orderNumber', async (request, reply) => {
  const { orderNumber } = request.params;

  try {
    const order = await prisma.order.findUnique({
      where: { orderNumber: String(orderNumber) },
      include: {
        customer: {
          select: { name: true, phone: true }
        }
      }
    });

    if (!order) {
      reply.status(404);
      return { success: false, error: `سفارشی با شماره پیگیری ${orderNumber} در دیتابیس یافت نشد!` };
    }

    return {
      success: true,
      order: {
        number: order.orderNumber,
        item: order.itemTitle,
        status: order.status,
        city: order.city,
        customerName: order.customer.name,
        customerPhone: order.customer.phone,
        updatedAt: order.updatedAt
      }
    };
  } catch (err) {
    fastify.log.error(err);
    reply.status(500);
    return { success: false, error: 'خطا در واکشی اطلاعات سفارش' };
  }
});

// ۴. مسیر ثبت سفارش جدید در دیتابیس (برای تست و اضافه کردن محصول)
fastify.post('/api/orders', async (request, reply) => {
  const { orderNumber, itemTitle, city, customerPhone, customerName } = request.body || {};

  if (!orderNumber || !itemTitle || !customerPhone) {
    reply.status(400);
    return { success: false, error: 'شماره سفارش، نام کالا و تلفن مشتری الزامی هستند.' };
  }

  try {
    // ۱. پیدا کردن یا ساخت مشتری
    const customer = await prisma.customer.upsert({
      where: { phone: customerPhone },
      update: {},
      create: { name: customerName || 'مشتری جدید', phone: customerPhone }
    });

    // ۲. ثبت سفارش متصل به آن مشتری
    const newOrder = await prisma.order.create({
      data: {
        orderNumber: String(orderNumber),
        itemTitle: itemTitle,
        city: city || 'نامشخص',
        customerId: customer.id
      }
    });

    reply.status(201); // 201 Created
    return {
      success: true,
      message: 'سفارش با موفقیت در دیتابیس پایدار ذخیره شد.',
      order: newOrder
    };
  } catch (err) {
    if (err.code === 'P2002') {
      reply.status(409); // Conflict - تکراری
      return { success: false, error: 'این شماره سفارش قبلاً در دیتابیس ثبت شده است!' };
    }
    fastify.log.error(err);
    reply.status(500);
    return { success: false, error: 'خطای سیستمی در ثبت سفارش' };
  }
});

// ۵. روشن کردن موتور سرور روی پورت ۳۰۰۰
const startServer = async () => {
  try {
    const address = await fastify.listen({ port: 3000, host: '0.0.0.0' });
    console.log(`\n🚀 سرور سفیر با اتصال زنده به دیتابیس روی ${address} بیدار شد!\n`);
  } catch (err) {
    fastify.log.error(err);
    process.exit(1);
  }
};

startServer();
```

## ۶. 🧗 تمرین‌های تثبیت مهارت (دست‌به‌آچار شدن چریکی)

برای تسلط کامل روی Prisma و پایگاه داده رابطه‌ای، این دو چالش را خودت انجام بده:

### تمرین اول: به‌روزرسانی وضعیت سفارش (`PATCH /api/orders/:orderNumber`)

```javascript
const chats = await prisma.chatMessage.findMany({
```
