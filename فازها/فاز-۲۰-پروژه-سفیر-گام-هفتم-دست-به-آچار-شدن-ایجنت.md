# فاز ۲۰ — پروژه سفیر: گام هفتم (دست‌به‌آچار شدن — ایجنت‌های خودمختار و اجرای ابزارها با Function Calling)

> 🧒 **داستان کل فاز:**  
> تا دیروز در شرکت سفیر، هوش مصنوعی ما فقط یک «مشاور خوش‌صحبت» بود (Chatbot معمولی)!  
> اگر مشتری به او می‌گفت: «من آدرسم عوض شده، بسته‌ام را به اصفهان بفرستید»، مشاور با لحنی بسیار مودبانه می‌گفت: «حتماً! شما باید وارد سایت شوید، روی دکمه تنظیمات کلیک کنید و آدرس را عوض کنید». یعنی کار را خودش انجام نمی‌داد و فقط به مشتری آدرس می‌داد!  
> اما از امروز ما می‌خواهیم او واقعاً **دست‌به‌آچار شود (یک ایجنت هوشمند / AI Agent)**!  
> ما یک کمربند ابزار دور کمر او می‌بندیم:
> 1. آچار اول: ابزار استعلام سفارش در دیتابیس (`getOrderDetails`).
> 2. آچار دوم: ابزار ویرایش آدرس و شهر تحویل در دیتابیس (`updateOrderCity`).
> 3. آچار سوم: ابزار ثبت تیکت پشتیبانی و لغو سفارش (`cancelOrder`).
> 
> حالا وقتی مشتری می‌گوید: «سلام سفیر! من اسباب‌کشی کردم، لطفاً سفارش ۲۰۰۱ من رو به جای مشهد بفرستید شیراز»، ایجنت به صورت خودمختار نقشه می‌کشد (**Planning**):  
> اول ابزار استعلام را برمی‌دارد تا ببیند سفارش ۲۰۰۱ کجاست؛ وقتی دید هنوز در انبار است، آچار ویرایش آدرس را برمی‌دارد، شهر را در PostgreSQL به شیراز تغییر می‌دهد، کش قدیمی ردیس را پاک می‌کند، و در آخر با خوشحالی به مشتری می‌گوید: «انجام شد! آدرس سفارش ۲۰۰۱ شما با موفقیت به شیراز تغییر یافت».

## ۱. 🧰 جعبه‌ابزار مأموریت (دانلود قبل از شروع کار آفلاین)

برای این ایستگاه از همان کلاینت استاندارد `openai` و مدل‌های لوکال Ollama استفاده می‌کنیم:

### ۱. مدل‌های دارای قابلیت پشتیبانی از ابزارها (Tool Calling Support)
- **چرا نیاز داریم:** همه مدل‌های زبانی نمی‌توانند ابزار صدا بزنند! مدل باید برای این کار آموزش دیده باشد. خوشبختانه مدل‌های متن‌باز مدرن مثل `qwen2.5` و `llama3.2` این قابلیت را به صورت نیتیو و فوق‌العاده قوی دارند.
- **دستور اجرای مدل در ترمینال:**
  ```bash
  ollama run qwen2.5:0.5b
  # یا مدل قدرتمندتر برای تصمیم‌گیری پیچیده:
  # ollama run llama3.2:1b
  ```

## ۲. الفبای ایجنت‌ها به زبان یک کودک ۵ ساله (مفاهیم کلیدی)

> 🧒 **داستان این بخش:** فرض کن به یک روبات اسباب‌بازی یک آچار فرانسه و یک پیچ‌گوشتی داده‌ای. روبات چشم دارد و می‌بیند که پیچ صندلی شل شده است (**Reasoning/استدلال**). پیچ‌گوشتی را از کمربندش برمی‌دارد و پیچ را سفت می‌کند (**Action/عمل**). سپس نگاه می‌کند و می‌بیند صندلی محکم شد (**Observation/مشاهده**) و به تو می‌گوید: «صندلی درست شد!». این حلقه سه‌مرحله‌ای (فکر کن -> عمل کن -> ببین) قلب تپنده تمام ایجنت‌های هوش مصنوعی جهان است.

---

### ۲.۱. ایجنت چگونه کدهای ما را اجرا می‌کند؟ (پروتکل Function Calling)

یک سوءتفاهم بزرگ: مدل هوش مصنوعی **مستقیماً** به دیتابیس وصل نمی‌شود یا کدهای سرور ما را اجرا نمی‌کند!  
بلکه طبق این گفتگوی هوشمندانه پیش می‌رود:

```
۱. مشتری در چت: «شهر سفارش ۲۰۰۱ رو بکن شیراز»
۲. وب‌سرور: لیست ابزارها را به هوش مصنوعی می‌دهد (مثلاً: ابزاری دارم به نام updateOrderCity با ورودی‌های orderNumber و newCity).
۳. هوش مصنوعی به سرور می‌گوید: «من کدی اجرا نمی‌کنم، ولی لطفاً تو به جای من تابع updateOrderCity را با ورودی {"orderNumber":"2001", "newCity":"شیراز"} صدا بزن!»
۴. سرور کدهای جاوااسکریپت را اجرا می‌کند و شهر را در PostgreSQL عوض می‌کند.
۵. سرور نتیجه را به مدل پس می‌دهد: «تابع با موفقیت اجرا شد و وضعیت سفارش بروز گردید.»
۶. مدل به مشتری به زبان شیرین فارسی پیام می‌دهد: «سفارش ۲۰۰۱ شما با موفقیت به مقصد شیراز تغییر یافت!»
```

## ۳. تعریف کدهای جعبه‌ابزار و حلقه ایجنت در سفیر

کدهای زیر را در `server.js` قرار می‌دهیم:

```javascript
// server.js — نسخه ۳: گام هفتم (دست‌به‌آچار شدن — ایجنت خودمختار و Function Calling)

const fastify = require('fastify')({ logger: true });
const { PrismaClient } = require('@prisma/client');
const Redis = require('ioredis');
const { OpenAI } = require('openai');

const prisma = new PrismaClient();
const redis = new Redis({
  host: process.env.REDIS_HOST || '127.0.0.1',
  port: process.env.REDIS_PORT || 6379,
  maxRetriesPerRequest: null
});

const openai = new OpenAI({
  baseURL: process.env.AI_BASE_URL || 'http://localhost:11434/v1',
  apiKey: process.env.AI_API_KEY || 'ollama-local-offline'
});

const AI_MODEL = process.env.AI_MODEL_NAME || 'qwen2.5:0.5b';

// ۱. تعریف کاتالوگ ابزارهایی که در اختیار ایجنت قرار می‌دهیم
const AGENT_TOOLS = [
  {
    type: 'function',
    function: {
      name: 'getOrderDetails',
      description: 'استعلام جزئیات، وضعیت فعلی و شهر مقصد یک سفارش با شماره پیگیری',
      parameters: {
        type: 'object',
        properties: {
          orderNumber: { type: 'string', description: 'شماره پیگیری سفارش مانند 2001' }
        },
        required: ['orderNumber']
      }
    }
  },
  {
    type: 'function',
    function: {
      name: 'updateOrderCity',
      description: 'تغییر شهر مقصد و آدرس تحویل سفارش در صورتی که سفارش هنوز تحویل نشده باشد',
      parameters: {
        type: 'object',
        properties: {
          orderNumber: { type: 'string', description: 'شماره پیگیری سفارش' },
          newCity: { type: 'string', description: 'نام شهر جدید مقصد مانند شیراز یا اصفهان' }
        },
        required: ['orderNumber', 'newCity']
      }
    }
  }
];

// ۲. توابع واقعی جاوااسکریپت که ابزارها را روی دیتابیس اجرا می‌کنند
const toolHandlers = {
  // اجرای ابزار استعلام
  async getOrderDetails({ orderNumber }) {
    const order = await prisma.order.findUnique({
      where: { orderNumber: String(orderNumber) },
      include: { customer: { select: { name: true, phone: true } } }
    });

    if (!order) {
      return { found: false, error: `سفارشی با شماره ${orderNumber} در سیستم ثبت نشده است.` };
    }

    return {
      found: true,
      orderNumber: order.orderNumber,
      item: order.itemTitle,
      status: order.status,
      city: order.city,
      customerName: order.customer.name
    };
  },

  // اجرای ابزار تغییر شهر
  async updateOrderCity({ orderNumber, newCity }) {
    const order = await prisma.order.findUnique({ where: { orderNumber: String(orderNumber) } });
    if (!order) {
      return { success: false, error: `سفارش ${orderNumber} پیدا نشد.` };
    }

    if (order.status.includes('تحویل داده شده')) {
      return { success: false, error: 'این سفارش قبلاً تحویل شده و امکان تغییر مقصد وجود ندارد.' };
    }

    const updated = await prisma.order.update({
      where: { orderNumber: String(orderNumber) },
      data: { city: newCity }
    });

    // باطل‌سازی کش ردیس
    await redis.del(`order:${orderNumber}`);

    return {
      success: true,
      message: `شهر مقصد سفارش با موفقیت به ${newCity} تغییر یافت.`,
      updatedOrder: { orderNumber: updated.orderNumber, city: updated.city }
    };
  }
};

// نبض سلامت ایجنت و ابزارهای فعال
fastify.get('/health', async (request, reply) => {
  return {
    status: 'healthy',
    service: 'Safir Autonomous Agent Engine',
    activeTools: ['getOrderDetails', 'updateOrderCity'],
    aiModel: AI_MODEL,
    timestamp: new Date().toISOString()
  };
});

// ۳. روت گفتگوی هوشمند با ایجنت خودمختار (ReAct Loop)
fastify.post('/api/ai/agent-chat', async (request, reply) => {
  const { message } = request.body || {};

  if (!message || message.trim() === '') {
    reply.status(400);
    return { success: false, error: 'متن پیام الزامی است.' };
  }

  const startTime = Date.now();
  const messages = [
    {
      role: 'system',
      content: `تو ایجنت خودمختار و دست‌به‌آچار سامانه تدارکات سفیر هستی.
تو به ابزارهای واقعی برای استعلام سفارشات و ویرایش شهر مقصد دسترسی داری.
اگر کاربر سوالی پرسید که نیاز به اطلاعات دیتابیس دارد یا خواست تغییری ایجاد کند، از ابزارهای در اختیارت استفاده کن.
پاسخ نهایی را با لحنی بسیار صمیمی، حرفه‌ای و فارسی به کاربر اعلام کن.`
    },
    { role: 'user', content: message }
  ];

  try {
    // گام ۱: ارسال پیام کاربر و جعبه‌ابزار به مدل
    let response = await openai.chat.completions.create({
      model: AI_MODEL,
      messages,
      tools: AGENT_TOOLS,
      tool_choice: 'auto',
      temperature: 0.1
    });

    let responseMessage = response.choices[0].message;
    const actionsTaken = [];

    // گام ۲: آیا مدل درخواست اجرای ابزار داد؟ (Tool Calling Loop)
    if (responseMessage.tool_calls && responseMessage.tool_calls.length > 0) {
      messages.push(responseMessage); // اضافه کردن قصد مدل به تاریخچه گفتگو

      for (const toolCall of responseMessage.tool_calls) {
        const functionName = toolCall.function.name;
        const functionArgs = JSON.parse(toolCall.function.arguments);

        // اجرای تابع واقعی جاوااسکریپت
        const handler = toolHandlers[functionName];
        let toolResult = { error: 'ابزار ناشناخته' };

        if (handler) {
          toolResult = await handler(functionArgs);
        }

        actionsTaken.push({
          tool: functionName,
          input: functionArgs,
          output: toolResult
        });

        // بازگرداندن نتیجه اجرای تابع به مدل
        messages.push({
          role: 'tool',
          tool_call_id: toolCall.id,
          name: functionName,
          content: JSON.stringify(toolResult)
        });
      }

      // گام ۳: مدل با دیدن نتیجه اجرای ابزارها، پیام نهایی را به کاربر می‌گوید
      const secondResponse = await openai.chat.completions.create({
        model: AI_MODEL,
        messages,
        temperature: 0.1
      });

      responseMessage = secondResponse.choices[0].message;
    }

    const elapsed = Date.now() - startTime;

    return {
      success: true,
      executionTimeMs: elapsed,
      reply: responseMessage.content,
      actionsTaken
    };
  } catch (err) {
    request.log.error(err);
    reply.status(500);
    return { success: false, error: 'خطا در چرخه تصمیم‌گیری ایجنت', details: err.message };
  }
});

fastify.listen({ port: 3000, host: '0.0.0.0' }).then(addr => {
  console.log(`🤖 ایجنت خودمختار سفیر با جعبه‌ابزار کامل روی ${addr} آغاز به کار کرد!`);
});
```

## ۵. تمرین‌های تثبیت و چالش چریکی

1. **چالش سقف تکرار (Max Recursion Steps):**  
   اگر دو ابزار به هم وابسته باشند و مدل وارد لوپ بی‌نهایت صدا زدن توابع شود، سرور هنگ می‌کند. با قرار دادن یک شمارنده `maxSteps = 5`، جلوی مصرف بی‌رویه منابع را بگیر.
2. **چالش تاییدیه انسانی (Human-in-the-Loop):**  
   برای عملیات حساس مانند لغو قطعی سفارش یا استرداد پول، ایجنت نباید بلافاصله ابزار را اجرا کند؛ بلکه باید پیام تولید کند: «آیا مطمئن هستید که می‌خواهید سفارش ۲۰۰۱ لغو شود؟ لطفاً کلمه تایید را بنویسید».
