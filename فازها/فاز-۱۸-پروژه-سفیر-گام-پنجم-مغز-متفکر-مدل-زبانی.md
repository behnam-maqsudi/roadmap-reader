# فاز ۱۸ — پروژه سفیر: گام پنجم (مغز متفکر — اتصال به مدل‌های زبانی LLM با خروجی معتبر JSON)

> 🧒 **داستان کل فاز:**  
> فرض کن در شرکت سفیر، یک دانشمند نابغه اما فوق‌العاده حواس‌پرت و شاعرپیشه استخدام کرده‌ایم (**مدل زبانی بزرگ یا LLM**)!  
> او همه زبان‌های دنیا را بلد است و میلیاردها کتاب خوانده، اما یک ایراد بزرگ دارد: هر بار مشتری از او می‌پرسد «بسته من کجاست؟»، دانشمند به جای یک پاسخ کوتاه و مشخص، ۱۰ بیت شعر می‌گوید، درباره تاریخچه پست در دوران هخامنشیان انشا می‌نویسد و در آخر با لحنی دراماتیک می‌گوید بسته در راه است!  
> اگر سیستم نرم‌افزاری و دیتابیس ما بخواهد این شعرها و متن‌های طولانی را بفهمد، کامپیوتر هنگ می‌کند! کامپیوترها شعر نمی‌فهمند؛ کامپیوترها فقط **فرم‌های رسمی و مرتب (JSON)** می‌فهمند:  
> `{ "intent": "پیگیری_سفارش", "orderNumber": "2001", "sentiment": "عصبانی" }`  
> در این ایستگاه، یاد می‌گیریم چطور به این نابغه پرحرف یک **فرم با خط‌کشی دقیق (JSON Schema)** بدهیم و یک ناظر سخت‌گیر به نام **Zod** بالای سرش بگذاریم تا پاسخ‌هایش ۱۰۰٪ تمیز، قابل پردازش با کد، و بدون توهم تولید شوند؛ چه با مدل‌های ابری و چه به صورت کاملاً آفلاین روی لپ‌تاپ خودت با **Ollama**!

## ۱. 🧰 جعبه‌ابزار مأموریت (دانلود قبل از شروع کار آفلاین)

برای این ایستگاه، هم قابلیت اجرای **آفلاین کامل روی کامپیوتر با LM Studio یا Ollama** را فراهم می‌کنیم و هم اتصال به مدل‌های ابری:

### ۱. موتور اجرای هوش مصنوعی آفلاین (`LM Studio` یا `Ollama`)
- **چرا نیاز داریم:** ابزارهایی شگفت‌انگیز که مدل‌های متن‌باز قدرتمند مثل `Qwen2.5 Coder 7B` و Llama 3 را مستقیماً روی CPU یا GPU ویندوز اجرا می‌کنند و یک وب‌سرور استاندارد سازگار با OpenAI می‌سازند:
  * **اگر با LM Studio کار می‌کنی:** در تب Local Server دکمه **Start Server** را بزن تا روی پورت `http://localhost:1234/v1` فعال شود (مدل `Qwen2.5 Coder 7B Instruct`).
  * **اگر با Ollama کار می‌کنی:** پورت `http://localhost:11434/v1` را در اختیار داری با دستور `ollama run qwen2.5-coder:7b`.
- بدون نیاز به فیلترشکن، بدون نیاز به اینترنت و ۱۰۰٪ رایگان و آفلاین!
- **تست سلامت در ترمینال:**
  ```bash
  # تست LM Studio:
  curl http://localhost:1234/v1/models
  # یا تست Ollama:
  curl http://localhost:11434/api/tags
  ```

### ۲. پکیج ارتباطی رسمی (`openai`)
- **چرا نیاز داریم:** کلاینت استاندارد جهانی. نکته جالب اینجاست که Ollama، LocalAI و تمام ابزارهای لوکال هم دقیقاً از همین استاندارد OpenAI API پیروی می‌کنند؛ یعنی با همین یک پکیج، بدون تغییر حتی یک خط کد، می‌توانی بین لپ‌تاپ آفلاین و سرورهای ابری سوییچ کنی!
- **دستور نصب:**
  ```bash
  npm install openai
  ```

### ۳. پکیج اعتبارسنجی داده‌ها (`zod`)
- **چرا نیاز داریم:** سخت‌گیرترین بازرس دنیای جاوااسکریپت! مطمئن می‌شود خروجی متنی هوش مصنوعی به یک آبجکت تایپ‌سیف و بدون فیلد گم‌شده تبدیل شده است.
- **دستور نصب:**
  ```bash
  npm install zod
  ```

## ۲. الفبای مدل‌های زبانی به زبان یک کودک ۵ ساله (مفاهیم کلیدی)

> 🧒 **داستان این بخش:** مدل زبانی شبیه طوطی بسیار باهوشی است که حدس می‌زند «کلمه بعدی چه باید باشد؟». اگر به طوطی بگویی «امروز هوا چطوره؟»، شروع به پرحرفی می‌کند. اما اگر یک برگه چهارخانه جلویش بگذاری و بگویی: «فقط داخل این سه خانه را پر کن: ۱. دما ۲. باران ۳. باد»، او خود را با خانه‌ها وفق می‌دهد. به این کار در مهندسی نرم‌افزار **خروجی ساختاریافته (Structured Output)** می‌گویند.

---

### ۲.۱. چرا خروجی آزاد متنی (Plain Text) برای برنامه‌نویسان خطرناک است؟

فرض کن کلاینت چت سفیر این پیام را از خریدار می‌گیرد:
> *«سلام داداش! من دیشب سفارش شماره ۲۰۱۰ رو ثبت کردم، کی می‌فرستید شیراز؟»*

اگر به مدل بگویی این را تحلیل کن و مدل جواب بدهد:
> *«به نام خدا، با سلام خدمت شما مشتری گرامی، طبق بررسی‌های ما سفارش شماره ۲۰۱۰ مربوط به کالای شما در صف ارسال است...»*

برنامه ما چطور باید شماره سفارش (`2010`) را از دل این متن بیرون بکشد تا در دیتابیس PostgreSQL استعلام کند؟ با RegEx؟ اگر کاربر نوشت «سفارشم دویست و ده است» چی؟  
راهکار درست این است که به مدل دستور دهیم **فقط و فقط یک آبجکت JSON معتبر** بازگرداند:
```json
{
  "intent": "TRACK_ORDER",
  "orderNumber": "2010",
  "destinationCity": "شیراز",
  "sentiment": "NEUTRAL",
  "suggestedReply": "سفارش ۲۰۱۰ شما در حال بررسی برای ارسال به شیراز است."
}
```
حالا کد Fastify ما در یک میکروثانیه می‌گوید: `const id = aiResult.orderNumber` و مستقیم به دیتابیس یا ردیس وصل می‌شود!

---

### ۲.۲. مثلث طلایی پرامپت مهندسی: System Prompt، User Input و JSON Schema

برای اینکه مدل زبان به یک کامپیوتر مطیع تبدیل شود، سه چیز به او می‌دهیم:
1. **دستورالعمل سیستم (System Prompt):** نقاب و هویت او را مشخص می‌کند («تو دستیار هوشمند سفیر هستی، فقط با فرمت JSON پاسخ بده»).
2. **پیام کاربر (User Input):** متنی که مشتری در اپ تایپ کرده است.
3. **فرمت پاسخ (Response Format):** با پارامتر `response_format: { type: "json_object" }` خروجی را در قالب آبجکت قفل می‌کنیم.

## ۳. ارتقای کدهای پروژه سفیر (اتصال Fastify به مغز متفکر)

کدهای زیر را در `server.js` قرار می‌دهیم. سرور هم می‌تواند به **Ollama لوکال** (آفلاین) وصل شود و هم به هر API سازگار با استاندارد OpenAI:

```javascript
// server.js — نسخه ۳: گام پنجم (مغز متفکر — اتصال Fastify به LLM با خروجی معتبر JSON)

require('dotenv').config();
const fastify = require('fastify')({ logger: true });
const { PrismaClient } = require('@prisma/client');
const { PrismaPg } = require('@prisma/adapter-pg');
const Redis = require('ioredis');
const { OpenAI } = require('openai');
const { z } = require('zod');

const adapter = new PrismaPg({ connectionString: process.env.DATABASE_URL });
const prisma = new PrismaClient({ adapter });
const redis = new Redis({
  host: process.env.REDIS_HOST || '127.0.0.1',
  port: process.env.REDIS_PORT || 6379,
  maxRetriesPerRequest: null
});

// ۱. تنظیم کلاینت هوش مصنوعی (پیش‌فرض: Ollama لوکال روی پورت 11434 بدون نیاز به اینترنت)
const openai = new OpenAI({
  baseURL: process.env.AI_BASE_URL || 'http://localhost:11434/v1',
  apiKey: process.env.AI_API_KEY || 'ollama-local-offline'
});

const AI_MODEL = process.env.AI_MODEL_NAME || 'qwen2.5:0.5b';

// ۲. تعریف فرم رسمی و سخت‌گیرانه با Zod (اعتبارسنجی خروجی هوش مصنوعی)
const AiAnalysisSchema = z.object({
  intent: z.enum(['TRACK_ORDER', 'COMPLAINT', 'GENERAL_QUESTION', 'CANCEL_ORDER']),
  orderNumber: z.string().nullable(),
  sentiment: z.enum(['HAPPY', 'NEUTRAL', 'ANGRY']),
  urgency: z.enum(['LOW', 'MEDIUM', 'HIGH']),
  suggestedReply: z.string().min(5)
});

// نبض سلامت سرور و ارتباط با مغز متفکر AI
fastify.get('/health', async (request, reply) => {
  let aiStatus = 'disconnected';
  try {
    const models = await openai.models.list();
    aiStatus = `connected (مدل فعال: ${AI_MODEL})`;
  } catch (err) {
    aiStatus = `offline (${err.message})`;
  }

  return {
    status: 'healthy',
    service: 'Safir Core + AI Brain',
    aiEngine: aiStatus,
    timestamp: new Date().toISOString()
  };
});

// ۳. روت تحلیل هوشمند پیام‌های ورودی مشتری با مدل زبانی
fastify.post('/api/ai/analyze-message', async (request, reply) => {
  const { message, customerPhone } = request.body || {};

  if (!message || message.trim() === '') {
    reply.status(400);
    return { success: false, error: 'متن پیام مشتری نمی‌تواند خالی باشد!' };
  }

  const startTime = Date.now();

  try {
    // صدا زدن مدل زبانی با پرامپت مهندسی‌شده برای خروجی JSON
    const response = await openai.chat.completions.create({
      model: AI_MODEL,
      response_format: { type: 'json_object' },
      messages: [
        {
          role: 'system',
          content: `تو هوش مصنوعی تحلیل‌گر سامانه تدارکات و لجستیک «سفیر» هستی.
وظیفه تو این است که پیام خریدار را خوانده و دقیقاً یک آبجکت معتبر JSON با این فیلدها بسازی:
- "intent": یکی از مقادیر ["TRACK_ORDER", "COMPLAINT", "GENERAL_QUESTION", "CANCEL_ORDER"]
- "orderNumber": رشته شماره سفارش اگر در پیام ذکر شده بود، در غیر این صورت مقدار null
- "sentiment": یکی از مقادیر ["HAPPY", "NEUTRAL", "ANGRY"]
- "urgency": یکی از مقادیر ["LOW", "MEDIUM", "HIGH"]
- "suggestedReply": یک پاسخ کوتاه، بسیار محترمانه و صمیمی به زبان فارسی برای مشتری

مهم: هیچ متنی جز ساختار JSON خروجی نده!`
        },
        {
          role: 'user',
          content: `پیام مشتری: "${message}"`
        }
      ],
      temperature: 0.1 // دمای پایین برای جلوگیری از خیال‌بافی و تضمین پاسخ ساختاریافته
    });

    const rawContent = response.choices[0].message.content;
    const parsedJson = JSON.parse(rawContent);

    // اعتبارسنجی قطعی با Zod: آیا مدل به عهدش وفا کرده است؟
    const validatedData = AiAnalysisSchema.parse(parsedJson);

    const elapsed = Date.now() - startTime;

    // ذخیره پیام و تحلیل هوشمند در دیتابیس
    await prisma.chatMessage.create({
      data: {
        sender: 'کاربر',
        content: `[تحلیل هوش مصنوعی: نیت=${validatedData.intent} | حس=${validatedData.sentiment}] ${message}`
      }
    });

    return {
      success: true,
      analysisTimeMs: elapsed,
      ai: validatedData
    };
  } catch (err) {
    request.log.error(err);
    reply.status(500);
    return {
      success: false,
      error: 'خطا در تحلیل پیام توسط مغز متفکر',
      details: err.message
    };
  }
});

fastify.listen({ port: 3000, host: '0.0.0.0' }).then(addr => {
  console.log(`🧠 مغز متفکر سفیر با اتصال به مدل زبانی روی ${addr} آماده خدمت شد!`);
});
```

## ۵. تمرین‌های تثبیت و چالش چریکی

1. **چالش به صفر رساندن توهم مدل (Temperature Tuning):**  
   چرا در سیستم‌های مالی و تدارکات مثل سفیر، پارامتر `temperature` باید روی عدد کمی مانند `0.1` یا `0` تنظیم شود؟ تاثیر بالا بردن آن به `0.9` روی ساختار فرمت JSON را در عمل بررسی کن.
2. **چالش تایپ زنده (Server-Sent Events / Streaming):**  
   چگونه می‌توان به جای انتظار ۲ ثانیه‌ای، توکن‌های پاسخ `suggestedReply` را به محض تولید کلمه به کلمه برای مشتری فرستاد؟ (در گام‌های بعدی روی وب‌سوکت پیاده‌سازی خواهیم کرد).
