## گام ۱: نصب و راه‌اندازی مستندات آفلاین (Zeal)

برنامه **Zeal** یک نرم‌افزار متن‌باز است که نسخه‌ی کامل داکیومنت تمام زبان‌ها و فریم‌ورک‌ها را دانلود کرده و همراه با موتور جستجوی سریع و بدون نیاز به اینترنت در اختیارتان می‌گذارد.

### ۱. دستور نصب در ویندوز (PowerShell):
```powershell
winget install Zeal.Zeal --accept-source-agreements --accept-package-agreements
```

### ۲. لیست داک‌های ضروری برای دانلود داخل Zeal:
بعد از اجرای Zeal، از منوی `Tools -> Docsets`:
1. دکمه **Download** را بزنید.
2. تیک موارد زیر را بزنید و دکمه **Download** را بزنید:
   * **NodeJS**
   * **TypeScript**
   * **JavaScript**
   * **PostgreSQL**
   * **Redis**
   * **Python 3**
   * **Docker**
   * **HTML** & **CSS**

## گام ۲: راه‌اندازی دستیار هوش مصنوعی محلی (LM Studio یا Ollama)

مدل‌های محلی در زمان قطعی اینترنت، جایگزین کامل Claude و ChatGPT برای اشکال‌زدایی کد، توضیح مفاهیم و کمک به طراحی سیستم هستند. شما می‌توانید از هر دو نرم‌افزار **LM Studio** یا **Ollama** استفاده کنید.

### روش اول: استفاده از LM Studio (محیط گرافیکی و سرور سازگار با OpenAI)
اگر از **LM Studio** استفاده می‌کنید، سیستم شما از قبل به مدل‌های قدرتمند زیر مجهز است:
1. **مدل کدنویس اصلی:** `Qwen2.5 Coder 7B Instruct` (برای نوشتن و دیباگ کدهای Fastify، Prisma و TypeScript)
2. **مدل کدنویس سبک و سریع:** `Qwen2.5 Coder 3B Instruct` (برای پاسخ‌های آنی و مصرف کم رم)
3. **مدل جستجو و وکتور:** `nomic-embed-text-v2-moe-GGUF` (برای سیستم دانشنامه و RAG)

#### نحوه فعال‌سازی سرور در LM Studio:
1. در منوی سمت چپ LM Studio روی آیکون **Local Server** (علامت `<->`) کلیک کنید.
2. از نوار بالای صفحه مدل `Qwen2.5 Coder 7B Instruct` را انتخاب کنید.
3. دکمه **Start Server** را بزنید تا سرور روی پورت `http://localhost:1234/v1` فعال شود.
4. در فایل `.env` پروژه متغیرهای زیر را قرار دهید:
   ```env
   AI_BASE_URL="http://localhost:1234/v1"
   AI_API_KEY="lm-studio"
   AI_MODEL_NAME="qwen2.5-coder-7b-instruct"
   EMBED_MODEL_NAME="nomic-ai/nomic-embed-text-v2-moe-GGUF"
   ```

### روش دوم: استفاده از Ollama (محیط خط فرمان)
اگر مایلید مستقیماً در خط فرمان بدون واسط گرافیکی کار کنید:
```powershell
# ۱. مربی و متخصص کدنویسی
ollama pull qwen2.5-coder:7b

# ۲. مدل عمومی و حل مسئله و استدلال
ollama pull llama3.1:8b

# ۳. مدل ساخت وکتور و امبدینگ برای RAG محلی
ollama pull nomic-embed-text
```

تست سریع در ترمینال (آفلاین):
```powershell
ollama run qwen2.5-coder:7b "چطور یک سرور ساده Fastify با روت تست بنویسم؟"
```

## گام ۳: کش کردن ایمیج‌های زیرساخت (Docker Images)

وقتی اینترنت قطع شود، دستور `docker compose up` در صورتی که ایمیج را قبلاً نداشته باشید با خطا متوقف می‌شود.

### ۱. باز کردن Docker Desktop:
نرم‌افزار **Docker Desktop** را در ویندوز باز کنید تا دیمن داکر به وضعیت `Running` (سبز) درآید.

### ۲. دانلود و ذخیره ایمیج‌های استاندارد در ترمینال:
```powershell
# دیتابیس با پشتیبانی از هوش مصنوعی و وکتور
docker pull pgvector/pgvector:pg16

# دیتابیس استاندارد Postgres
docker pull postgres:16-alpine

# سیستم کش و صف
docker pull redis:alpine

# محیط‌های ران‌تایم برای بیلد
docker pull node:20-alpine
docker pull python:3.11-slim
```

## گام ۴: آماده‌سازی کش پکیج‌های جاوااسکریپت و پایتون

در حالت آفلاین، npm نمی‌تواند پکیجی از رجیستری دانلود کند مگر اینکه آن پکیج قبلاً در کش محلی (`npm-cache`) ذخیره شده باشد یا در پوشه `node_modules` موجود باشد.

### اسکریپت آماده‌سازی پکیج‌های پرکاربرد (در پوشه پروژه):
```powershell
# نصب ابزارهای حیاتی بک‌اند
npm install fastify @fastify/cors @fastify/jwt zod prisma @prisma/client redis bullmq bcrypt jsonwebtoken dotenv pino

# نصب ابزارهای توسعه و تست آفلاین
npm install -D typescript tsx @types/node vitest @types/bcrypt @types/jsonwebtoken
```

## گام ۵: شبیه‌سازی تست آمادگی آفلاین (Pre-flight Test)

برای اینکه مطمئن شوید همه چیز بدون اینترنت کار خواهد کرد:
1. وای‌فای سیستم یا کابل شبکه خود را **قطع** کنید.
2. برنامه **Zeal** را باز کنید و یک کلمه مثل `fastify request` یا `Postgres CTE` جستجو کنید.
3. در ترمینال بنویسید:
   ```powershell
   ollama run qwen2.5-coder:7b "Explain how indexing works in PostgreSQL"
   ```
4. تست داکر در حالت بدون اینترنت:
   ```powershell
   docker run --rm -d --name test-pg -e POSTGRES_PASSWORD=test -p 5432:5432 postgres:16-alpine
   docker stop test-pg
   ```

اگر هر چهار آزمایش موفق بود، سیستم شما کاملاً **ضدضربه و آماده‌ی دو ماه شکوفایی و یادگیری عمیق در خلوت مهندسی** است.
