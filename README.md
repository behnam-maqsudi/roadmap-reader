# خوانندهٔ نقشهٔ راه

اپلیکیشنِ خواندنِ درس‌های نقشهٔ راهِ بک‌اند و مهندسی AI — با فونتِ محلی، بدون اینترنت.

## اجرا

```bash
npm install
npm run dev
```

بعد برو به <http://localhost:5173>.

## بررسی

```bash
node ابزار/بررسی-کامل.mjs
```

پنج بررسی را پشت‌سرهم اجرا می‌کند: متنِ فازها، ۱۲۶ تست، TypeScript، بیلد، و آفلاین‌بودن.

## آفلاین

هیچ‌چیز از اینترنت گرفته نمی‌شود:

- فونت‌ها در `public/fonts/` هستند (woff2 محلی، بدون CDN)
- متنِ درس‌ها با `import.meta.glob` داخل باندل می‌رود، نه با `fetch`
- فلش‌کارت‌ها در `محتوا/فازها/*.json` هستند و داخل باندل می‌روند

یعنی اپ روی شبکه‌ای که قطع است هم کامل کار می‌کند.

## ساختار

| مسیر | چیست |
|---|---|
| `فازها/` | متنِ درس‌ها — یک فایل `.md` برای هر فاز |
| `محتوا/فازها/` | فلش‌کارت‌ها و تمرین‌ها — یک `.json` برای هر فاز |
| `محتوا/استاندارد-نگارش.md` | قواعد نوشتنِ درس‌ها |
| `src/` | کدِ اپ |
| `ابزار/` | تست‌ها و بررسی‌ها |

## نکتهٔ مهم دربارهٔ تست‌ها

تست‌ها اسم‌ها و مسیرهای فارسی دارند. روی ویندوز `node --test` را حتماً با
پرچم زیر اجرا کن (وگرنه `import.meta.glob` و `vm.SourceTextModule` کار نمی‌کنند):

```bash
node ابزار/همه-تست.mjs
```

## شروعِ کار

مخزن را کلون کن، `npm install`، `npm run dev`. فایلِ `۰۰-راهنمای-شروع.md`
همان چیزی است که اپ موقعِ باز شدن نشان می‌دهد.
